# Mobile & Android Suite

This directory contains resources for building native Android APK wrappers and progressive web apps targeting warehouse tablets and barcode scanners.

## Files

* `build_apk.py`: Standalone Python script to generate Android APK packages.
* `AndroidManifest.xml`: Standard Android application manifest specifying internet permissions, fullscreen themes, and kiosk activity settings.

## Building the APK

```bash
python3 apps/mobile/build_apk.py
```
